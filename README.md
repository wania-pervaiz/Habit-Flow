# Habit Flow

Habit Flow is a React-based daily habit tracker that helps users track completed days and build consistent habits through a simple yearly progress view.

## Features

- Track daily habit completion
- View progress through a yearly heatmap
- Track current streak and longest streak
- Count total completed days
- Save progress using browser Local Storage
- Display motivational messages for completed days and months
- Prevent future dates from being marked as completed

## Technologies

- React
- JavaScript
- HTML
- CSS
- Local Storage

## Getting Started

Create and set up the project:

   npm create vite@latest habit-flow -- --template react
   cd habit-flow

Install the project dependencies:

   npm install

Start the development server:

   npm run dev

Replace the contents of src/App.jsx with the Habit Flow component code.
Open the provided local URL (usually http://localhost:5173) in your web browser.

## Purpose

This project was created to practice building an interactive React application with state management, local data storage, and a clean user interface.
